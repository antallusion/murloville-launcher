# MurloVille Launcher

Установщик и обновлятор игрового клиента для [MurloVille](https://play.murloville.ru) —
бесплатного сервера World of Warcraft 3.3.5a.

Одно окно на C# и WPF. Ставит игру с нуля, догоняет её до текущего состояния при
каждом запуске и запускает.

## Что скачивать

| Файл | Кому |
|---|---|
| `MurloVille-Setup-<версия>.exe` | обычный установщик с мастером — то, что нужно почти всем |
| `MurloVille.exe` | сам лаунчер отдельным файлом, если ставить ничего не хочется |

Оба лежат в [релизах](https://github.com/antallusion/murloville-launcher/releases)
и на [play.murloville.ru/download](https://play.murloville.ru/download).

## Что умеет

- **Ставит игру с нуля.** Спрашивает папку, проверяет свободное место заранее и
  скачивает около 16,5 ГБ.
- **Находит уже установленную игру.** Три пути к одному и тому же, потому что папка
  у всех лежит по-разному: вписать путь руками, выбрать в проводнике или нажать
  «Найти» — обойдёт диски. Быстрый поиск смотрит в реестр Blizzard и в обычные
  места вроде `C:\World of Warcraft` на каждом диске.
- **Продолжает с места обрыва.** Скачивает во временный `.part` запросами с
  диапазоном байт. На таком объёме обрыв связи — не исключение, а норма, и
  начинать заново было бы издевательством.
- **Проверяет каждый файл** по sha256 и только потом подменяет им прежний.
  Повреждённая закачка до игры не доедет.
- **Обновляет при каждом запуске** — сверяет список и качает только разошедшееся.
  Сначала сравнивает размер и лишь при совпадении считает хеш; результат сверки
  запоминается, поэтому повторный запуск проходит мгновенно.
- **Не лезет к занятым файлам.** Пока игра открыта, она держит MPQ, и заменить их
  нельзя. Лаунчер проверяет это до начала загрузки и объясняет причину, а не
  падает на первом файле после получаса скачивания.
- **Прописывает адрес сервера** в `realmlist.wtf` сам.

## Установка

Лаунчер ставится в `%LOCALAPPDATA%\Programs\MurloVille`, **не** в Program Files, и
это осознанный выбор. Программа пока без подписи: Windows и так покажет
предупреждение SmartScreen, а системная папка потребовала бы прав администратора и
добавила бы к нему запрос UAC. Два страшных окна подряд — верный способ потерять
половину желающих. Побочная выгода: удаление тоже не требует прав и не оставляет
мусора в системных папках.

Установка делает ярлыки на рабочем столе и в меню «Пуск», запись в «Установленных
приложениях» и, если согласиться, автозапуск вместе с Windows. При автозапуске окно
появляется свёрнутым: лаунчер молча догоняет обновления и не лезет на глаза.

Путь к найденной игре хранится в `%LOCALAPPDATA%\MurloVille\settings.txt`, отдельно
от программы, чтобы пережить переустановку.

Для развёртывания скриптом:

```
MurloVille-Setup-1.1.0.exe /VERYSILENT /TASKS="desktopicon,autostart"
MurloVille.exe --install
MurloVille.exe --uninstall
```

## Откуда берутся файлы

Что и откуда качать, написано в манифесте на сервере, а не в коде — хранилище
можно переносить, не пересобирая программу.

| Что | Где лежит | Почему так |
|---|---|---|
| Базовые файлы игры, ~16 ГБ | облачное хранилище | не меняются никогда, и их трафик не должен идти через игровой сервер: одна установка равна нескольким дням всего его исходящего трафика |
| Правки сервера, несколько МБ | игровой сервер | меняются часто |

Оформление окна тоже подгружается с сервера: внутри программы картинок нет.

## Формат манифеста

```json
{
  "launcherVersion": "1.1.0",
  "publicKey": "https://disk.yandex.ru/d/...",
  "totalBytes": 17796000000,
  "files": [
    {"path": "Data/common.MPQ", "size": 2856083241, "sha256": "…",
     "src": "yandex", "remote": "/wow/Data/common.MPQ"},
    {"path": "Data/ruRU/patch-ruRU-9.MPQ", "size": 75303, "sha256": "…",
     "src": "server"}
  ]
}
```

`src: server` — файл забирается с игрового сервера напрямую.
`src: yandex` — ссылка запрашивается через публичный API хранилища: она временная,
поэтому берётся заново на каждый файл.

## Сборка

Нужен .NET SDK 10 и Windows.

```bash
cd src
dotnet publish -c Release -o ../out
```

На выходе — один самодостаточный `MurloVille.exe`, которому не нужен установленный
.NET.

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php):

```bash
ISCC /DAppVersion=1.1.0 installer\MurloVille.iss
```

Обе сборки идут в GitHub Actions на каждый push; версия берётся из
`src/MurloLauncher.csproj`, чтобы не расходиться между лаунчером и установщиком.

## Подпись кода

Выпуски пока **не подписаны** — сертификат оформляется. Из-за этого Windows и
браузеры показывают предупреждение о неизвестной программе: проверки самого файла
за ним не стоит, система просто не знает эту подпись. Рядом с установщиком
публикуется отпечаток sha256, им можно сверить скачанное:

```
https://play.murloville.ru/client/MurloVille-Setup.exe.sha256
```

Подпись будет бесплатной, от SignPath Foundation — они подписывают только то, что
заведомо собрано из открытых исходников, поэтому сборка и вынесена в GitHub Actions.

> [SignPath Foundation](https://signpath.org).
