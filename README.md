# MurloVille Launcher

Установщик и обновлятор игрового клиента для [MurloVille](https://play.murloville.ru) —
бесплатного сервера World of Warcraft 3.3.5a.

Одно окно на C# и WPF. Ставит игру с нуля, догоняет её до текущего состояния при
каждом запуске и запускает. Ничего кроме этого не делает: в системе не прописывается,
служб не заводит, в реестр не лезет.

## Что умеет

- **Ставит игру с нуля.** Спрашивает папку, проверяет свободное место заранее и
  скачивает около 16,5 ГБ.
- **Продолжает с места обрыва.** Скачивает во временный `.part` запросами с
  диапазоном байт. На таком объёме обрыв связи — не исключение, а норма, и
  начинать заново было бы издевательством.
- **Проверяет каждый файл** по sha256 и только потом подменяет им прежний.
  Повреждённая закачка до игры не доедет.
- **Обновляет при каждом запуске** — сверяет список и качает только разошедшееся.
  Сначала сравнивает размер и лишь при совпадении считает хеш: гонять sha256 по
  трёхгигабайтному файлу, у которого и размер другой, незачем.
- **Прописывает адрес сервера** в `realmlist.wtf` сам.

## Откуда берутся файлы

Что и откуда качать, написано в манифесте на сервере, а не в коде — хранилище
можно переносить, не пересобирая программу.

| Что | Где лежит | Почему так |
|---|---|---|
| Базовые файлы игры, ~16 ГБ | облачное хранилище | не меняются никогда, и их трафик не должен идти через игровой сервер: одна установка равна нескольким дням всего его исходящего трафика |
| Правки сервера, несколько МБ | игровой сервер | меняются часто |

Оформление окна тоже подгружается с сервера: внутри программы картинок нет.

## Формат манифеста

```json
{
  "launcherVersion": "1.0.0",
  "publicKey": "https://disk.yandex.ru/d/...",
  "totalBytes": 17796000000,
  "files": [
    {"path": "Data/common.MPQ", "size": 2856083241, "sha256": "…",
     "src": "yandex", "remote": "/wow/Data/common.MPQ"},
    {"path": "Data/ruRU/patch-ruRU-9.MPQ", "size": 75303, "sha256": "…",
     "src": "server"}
  ]
}
```

`src: server` — файл забирается с игрового сервера напрямую.
`src: yandex` — ссылка запрашивается через публичный API хранилища: она временная,
поэтому берётся заново на каждый файл.

## Сборка

Нужен .NET SDK 10 и Windows.

```bash
cd src
dotnet publish -c Release
```

На выходе — один самодостаточный `MurloVille.exe`, которому не нужен
установленный .NET.
